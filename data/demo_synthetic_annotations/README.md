# ⚠️ NOT GOLD — pipeline-testing fixtures only

Every file in this directory is generated by
`scripts/data/build_demo_synthetic_annotations.py` from the rule-based AI
suggestions in `data/annotation/ai_suggestions.jsonl`, with a handful of
cells deliberately forced to disagree so `adjudicate.py`'s agreement/kappa
math has something non-trivial to compute.

**No human ever labeled these cells.** They exist solely so that
`adjudicate.py`, `generate_splits.py`, `aggregate_stats.py`, and
`generate_report.py` can be run, tested, and demonstrated before real
two-annotator gold labels exist. Every row carries
`"synthetic_test_fixture": true` for exactly this reason.

Do not:
- cite `adjudicated_demo.jsonl` as a gold dataset anywhere;
- use these files to make any claim about real Jeonbuk or metropolitan
  postings;
- copy these files forward once real annotation exists — replace them.

See `DATA_HANDOFF.md` for what real annotation work remains.
